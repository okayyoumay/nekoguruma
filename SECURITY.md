# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/okayyoumay/nekoguruma/security/advisories/new)
("Report a vulnerability" on the Security tab), not in a public issue or pull request.

Include what is affected (crate, binary, version or commit), how to reproduce it, and what an
attacker gains. You will get an answer in the advisory thread.

## Scope

Nekoguruma is under development and has no released version yet; reports against the `main`
branch are in scope. The intended trust boundaries are described in `docs/system-architecture.md`,
sections 11 (Artifact Ingestion and Trust Model) and 16 (Legal and Security Considerations).

Done when: a unary call against a listener that never answers fails within the configured deadline, and a `SubscribeEvent` stream stays open past it.
- **P3**: The worker gRPC client (`crates/worker-host/src/client.rs`) enables no HTTP/2 keep-alive, so a connection to a worker that stopped responding is only noticed by the next call's deadline, and an idle `SubscribeEvent` stream never notices. Done when: the client sends keep-alive pings with a timeout, and a test shows a stream to a listener that stops answering pings ends with an error.
- **P3**: Vendor IOCTLs with data are rejected in 64-bit mode (layout unknown); add a VCI profile entry (design 9.3) for them. Blocked on: a vendor that needs one.
